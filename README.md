# ComponentCorner Router

ComponentCorner Router is a React project I created to practice building a multi-page application using React Router. It builds on my previous ComponentCorner projects by adding navigation and different pages.

## Features

- Multi-page navigation
- React Router
- Static routes
- Dynamic routes with URL parameters
- Reusable React components
- Product pages
- Navigation between different parts of the application

## Technologies Used

- React
- React Router
- JavaScript
- HTML
- CSS
- Vite
- Git and GitHub

## What I Learned

This project helped me understand how routing works in React applications. I learned how to create routes, navigate between pages, and use URL parameters for dynamic pages. I also practiced organizing a larger React project while continuing to use reusable components.
